# The Serenity Framework's website

The site at https://serenityframework.github.io/: downloads, what the Framework does, the theory behind Serenity's design, and how she works with other agents.

It's plain HTML and CSS, with its fonts bundled (their licences are in `fonts/`), no scripts and no trackers. GitHub Pages publishes `main` as it is.

The apps themselves are in [serenity](https://github.com/serenityframework/serenity) (the Framework), [serenity-desktop](https://github.com/serenityframework/serenity-desktop) (the Desktop App) and [serenity-desktop-hub](https://github.com/serenityframework/serenity-desktop-hub) (the Hub). Those repos are private for now.
